# Готова збірка

Самодостатні (self-contained, .NET runtime вже всередині — окремо ставити не потрібно) білди `WinService` і `RDPMonitor` під win-x64, зібрані з вихідників цього репозиторію.

## Як завантажити

**Важливо:** усі файли цієї папки потрібні одночасно — `install.ps1` розпаковує `WinService.zip` і `RDPMonitor.zip`, які повинні лежати поряд з ним. Якщо завантажити лише `install.ps1` окремо (наприклад, кнопкою "Raw" на GitHub) — він просто не знайде потрібні архіви і завершиться з помилкою.

Тому качайте весь репозиторій одним архівом, а не окремі файли:

1. На сторінці репозиторію натисніть зелену кнопку **Code → Download ZIP** (або `git clone https://github.com/kotdn/rdp_SRV_mon.git`).
2. Розпакуйте завантажений архів.
3. Перейдіть у розпаковану папку `Install\` — там уже все потрібне разом.

## Встановлення

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
cd Install
.\install.ps1 -StartMonitor
```

Запускати від адміністратора. `-StartMonitor` — одразу відкрити GUI-монітор після встановлення служби (можна опустити і запустити його пізніше вручну/ярликом).

Перед встановленням скрипт визначає країну за IP (через ip-api.com) і продовжує лише для України; якщо сервіс геолокації недоступний — попереджає і все одно продовжує встановлення. Прапорець `-SkipGeoCheck` повністю вимикає цю перевірку.

Тексти обох "сторінок" встановлення (привітання і результат гео-перевірки) беруться з `install.config.json` поряд зі скриптом — редагуйте його напряму, `install.ps1` міняти не потрібно:

```json
{
  "welcome": "Текст привітання (сторінка 1)",
  "secondPage": {
    "ua": "Текст для України",
    "other": "Текст для інших країн, {0} — підставиться код країни"
  }
}
```

Якщо файлу немає або в ньому не вистачає ключа — використовується значення за замовчуванням із самого скрипта.

Скрипт: зупиняє і видаляє попередню версію служби (якщо є), розпаковує `WinService.zip`/`RDPMonitor.zip` у `C:\Program Files\RDPSecurityService`, реєструє і запускає службу `RDPSecurityService`, створює ярлики монітора на робочому столі та в меню Пуск. Конфіг і логи — у `C:\ProgramData\RDPSecurityService` (не чіпаються при перевстановленні).

## Оновлення до нової версії

Просто запустіть `install.ps1` знову зі свіжорозпакованого пакета — стара служба буде коректно зупинена і замінена, firewall-правила і конфіг зберігаються.

## Зібрати самому замість готового пакета

```powershell
cd WinService
dotnet publish -c Release -r win-x64 --self-contained true -o out
cd ..\monitor
dotnet publish -c Release -r win-x64 --self-contained true -o out
```
